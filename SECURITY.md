# Security Policy

## Reporting Vulnerabilities

The NodeBox team takes security isolation extremely seriously. If you discover a security vulnerability or sandbox escape vector within NodeBox, please report it privately rather than opening a public issue.

### Preferred Disclosure Method

Email security disclosures to **security@nodebox.dev** or submit a private security advisory via GitHub Security Advisories.

### Response Time

We aim to respond to security reports within 24 hours and issue patches within 48 hours for high-severity sandbox breakouts.
