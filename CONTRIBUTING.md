# Contributing to NodeBox

Thank you for your interest in contributing to **NodeBox**! We welcome bug reports, feature requests, documentation improvements, and pull requests.

## Code of Conduct

Please treat all members of the community with respect, kindness, and professionalism.

## Getting Started

1. Fork the repository on GitHub: `https://github.com/nodebox-dev/nodebox`
2. Clone your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/nodebox.git
   cd nodebox
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start development server:
   ```bash
   npm run dev
   ```

## Pull Request Guidelines

- Ensure your code passes TypeScript checks: `npm run lint`
- Ensure production build passes: `npm run build`
- Provide a clear title and description explaining the rationale behind your changes.

Thank you for helping make NodeBox the standard for AI agent sandboxing!
